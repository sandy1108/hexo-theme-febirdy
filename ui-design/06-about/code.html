关于博主

关于本站

本站基于静态框架 Hexo 构建，搭配专门量身定制的专属主题 hexo-theme-febirdy。摒弃冗余的花哨动效与非必要脚本，旨在打造一处纯粹、克制、且极为适合长时间沉浸阅读的技术自留地。
